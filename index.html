Technical Overview

Built for accuracy.
Designed for speed.

A modern mobile-first stack powering receipt intelligence from snap to settlement.

📱
React Native + Expo
Cross-platform mobile app targeting iOS first, with web support via Vite. Styled with Nativewind (Tailwind for React Native).
TypeScript
👁️
Google Cloud Vision API
OCR engine that reads printed and handwritten receipts with high accuracy, extracting item names, quantities, and prices.
ML / Computer Vision
🐍
Python Backend
Lightweight Python API handles receipt processing, item parsing, and tax/tip distribution logic with clean REST endpoints.
REST API
🗄️
Supabase
Postgres database with real-time subscriptions. Users, sessions, receipt data, and basket assignments stored and synced instantly.
PostgreSQL · Realtime
🎯
Drag & Drop Engine
Custom gesture-based item assignment UI lets users intuitively assign receipt items to individual baskets with live total recalculation.
React Native Gesture Handler
🧮
Smart Cost Splitting
Proportional tax and tip distribution based on item subtotals. Shared items split evenly. Every cent accounted for.
Exact Math · No Rounding Errors
